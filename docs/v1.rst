Amazon Ads API v1
=================

The unified generation

The v1 endpoints live under ``/adsApi/v1/`` and are **not** split by product.
Every call targets the same resource and the product is selected in the request
body through ``adProductFilter``. This supersedes the per-product v2/v3 endpoints
(``/v2/sp/...``, ``/sp/...``).
