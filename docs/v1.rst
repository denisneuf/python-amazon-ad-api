Amazon Ads API v1
=================

The unified generation: the v1 endpoints live under ``/adsApi/v1/`` and are
**not** split by product. Every call targets the same resource and the product is
selected in the request body through ``adProductFilter``. This supersedes the
per-product v3 endpoints (``/sp/...``, ``/sb/...``, ``/sd/...``).
