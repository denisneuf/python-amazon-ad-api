Amazon Ads API v0
=================

The per-product endpoints, superseded by :doc:`v1`.

Each product keeps its own path prefix and its own generations -- Sponsored
Products, Sponsored Brands and Sponsored Display were separate APIs, not
versions of one API. They stay here for reference and for the products that have
no unified equivalent yet.

.. warning::

    **Legacy, on the path to deprecation.** Amazon publishes these as product
    specific APIs that predate the v1 domain model. Use them only when the
    functionality you need is not yet available in the Amazon Ads API v1, and
    all v0 APIs are on the path to deprecation and not recommended for new
    integrations unless they provide functionality not yet available in v1.

    New code should target :doc:`v1`. The vendor states it in its own words, `v0 overview`_.


.. _`v0 overview`: https://advertising.amazon.com/API/docs/en-us/reference/v0-overview

The Sponsored Brands API, in 3.0 and 4.0: campaigns, ad groups, keywords,

The Sponsored Display API: campaigns, ad groups, targeting, creatives and
reports.
