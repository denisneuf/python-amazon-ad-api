.. note::

    Amazon exposes several Sponsored Products API generations. The **v1** endpoints
    (``/adsApi/v1/...``) are the current generation and supersede v3.

.. warning::

    Version 2 is deprecated (6/30/2023) and its methods are commented out in the
    source. Version 3 remains available, but its ``list_campaigns`` method is
    deprecated in favour of the v1 ``query_campaigns``.
